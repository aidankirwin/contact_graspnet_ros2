# Contact-GraspNet ROS 2 Wrapper  

This package provides a ROS 2 Node wrapper around **Contact-GraspNet** (PyTorch implementation)

This design allows us to:  
- Use CGN and UOIS inside of a ROS2 environment 
- Cleanly return grasp results (`poses`, `scores`, `object_ids`) to the ROS 2 ecosystem.
